## 项目简介

本项目是一套**工程化的量化策略研究框架**，以ETF（交易型开放式指数基金）为研究标的，实现从数据处理、策略开发、回测验证到交易归因分析的完整研究链路。项目采用模块化设计，将数据层、策略层、回测引擎、绩效评估、参数寻优、可视化等功能解耦，便于策略迭代与扩展。

项目源于量化实习期间的业务实践，将ETF套利、策略回测、交易日志分析等实习内容沉淀为可复现、可扩展的代码工程。

## 核心功能

### 1. 多策略回测引擎
- **双均线策略（DualMA）**：短期均线与长期均线金叉买入、死叉卖出，经典趋势跟踪策略
- **MACD策略**：MACD线与信号线交叉判断动量趋势
- **布林带策略（Bollinger）**：价格触及上下轨进行均值回归交易
- 统一策略基类，自动记录交易日志，支持自定义策略快速接入

### 2. 全套绩效指标评估
独立实现量化绩效评价体系，不依赖框架内置分析器：

| 类别 | 指标 | 说明 |
|------|------|------|
| 收益指标 | 总收益率、年化收益率 | 复利年化计算 |
| 风险指标 | 最大回撤、年化波动率、下行波动率 | 衡量策略风险暴露 |
| 风险调整收益 | 夏普比率、索提诺比率、卡玛比率 | 单位风险的超额收益 |
| 交易统计 | 胜率、盈亏比、平均持仓周期、最大连续亏损 | 交易行为分析 |

### 3. 参数网格寻优
- 对双均线策略的快慢线周期进行网格搜索
- 支持按夏普比率、年化收益率、卡玛比率等多目标排序
- 输出参数热力图，直观展示参数敏感性
- 自动识别最优参数组合

### 4. 多维度交易归因分析
回答"钱是怎么赚的、怎么亏的"：
- **整体概览**：总盈亏、胜率、盈亏比、单笔交易期望值
- **时间维度**：按月统计盈亏，识别策略有效时段
- **持仓周期维度**：短线/中线/长线交易盈亏对比
- **盈亏分布**：最大单笔盈亏、中位数、标准差
- **连续盈亏分析**：最大连续盈利/亏损次数，评估资金压力

### 5. 可视化报告
- 多策略净值曲线对比图
- 净值与回撤联合分析图
- 参数寻优热力图
- 月度盈亏柱状图

## 项目架构

```
quant-strategy/
├── config/
│   ├── __init__.py
│   └── settings.py          # 全局配置（回测参数、标的、手续费等）
├── src/
│   ├── __init__.py
│   ├── data_loader.py       # 数据加载模块（模拟数据/真实行情）
│   ├── strategies.py        # 策略实现（双均线/MACD/布林带）
│   ├── metrics.py           # 绩效指标计算（夏普/回撤/索提诺等）
│   ├── backtest_engine.py   # 回测引擎封装
│   ├── optimizer.py         # 参数网格寻优
│   ├── trade_analyzer.py    # 交易归因分析
│   └── visualizer.py        # 可视化图表生成
├── tests/
│   ├── test_metrics.py      # 绩效指标单元测试
│   └── test_data_loader.py  # 数据加载单元测试
├── data/                    # 行情数据目录
├── output/                  # 回测结果、图表输出目录
├── main.py                  # 主入口：一键运行完整回测流程
├── run_optimization.py      # 参数寻优入口
├── requirements.txt         # 依赖清单
├── .gitignore
└── README.md
```

### 设计原则
- **模块化**：各功能模块独立，单一职责，便于测试和替换
- **可扩展**：策略基类统一接口，新增策略只需继承BaseStrategy并注册
- **可复现**：配置集中管理，模拟数据固定随机种子，结果可复现
- **工程化**：包含单元测试、配置管理、输出目录规范

## 快速开始

### 环境要求
- Python 3.9+
- 依赖库：backtrader, pandas, numpy, matplotlib

### 安装依赖
```bash
pip install -r requirements.txt
```

### 运行完整回测流程
```bash
python main.py
```
执行后将依次完成：数据加载 → 双均线回测 → 交易归因分析 → 多策略对比 → 可视化图表生成，结果保存至 `output/` 目录。

### 运行参数寻优
```bash
python run_optimization.py
```
对双均线快慢线参数进行网格搜索，输出Top10参数组合及参数热力图。

### 运行单元测试
```bash
pytest tests/ -v
```

## 回测配置说明

在 `config/settings.py` 中可调整：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| initial_cash | 1,000,000 | 初始资金 |
| commission_rate | 0.0003 | 佣金费率（万三） |
| slippage | 0.001 | 滑点（千一） |
| risk_free_rate | 0.025 | 无风险利率（年化） |
| fast_period / slow_period | 5 / 20 | 双均线默认参数 |
| fast_range / slow_range | (3,20) / (20,60) | 参数寻优范围 |

## 数据源说明

项目默认使用**几何布朗运动（GBM）模拟行情数据**，无需网络即可运行，用于策略逻辑验证与框架测试。模拟数据具备以下特征：
- 跳过周末，生成真实交易日序列
- 价格路径符合几何布朗运动，带有趋势与波动
- OHLC价格关系合理（最高价≥收盘价≥最低价）
- 固定随机种子，结果可复现

如需接入真实行情，将 `DataLoader.load(use_sim=False)` 即可，底层通过yfinance获取真实ETF数据（需网络环境支持）。
