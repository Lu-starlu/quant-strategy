# data 文件夹
>本目录用于存放本地原始交易日志、ETF历史行情原始文件。
出于数据保密，原始实习交易账表不上传到GitHub。
- 本地使用：将交易日志Excel放置到此目录，运行代码读取做盈亏归因分析。
- GitHub仓库：仅保留目录结构，无原始业务数据。
# ETF量化策略与实习复盘项目
> 本项目为实习成果项目化沉淀，原始交易数据属于机构保密资料，仅本地留存，不对外公开。

## 项目简介
结合ETF套利实习经历，完成：
1. ETF轮动策略Python回测，参数寻优；
2. 实习复盘文档：ETF套利机制、交易日志复盘总结；
3. 交易日志盈亏归因分析，从标的、交易时段、策略维度统计盈亏。

## 环境依赖
pip install -r requirements.txt

## 运行
1. 策略回测：python main.py
2. 参数优化：python run_optimization.py

## 文件说明
- intern_report.md：完整实习复盘笔记，面试核心材料
- output：回测图表、盈亏输出报表
- data：存放本地交易日志原始Excel，不上传至公网
