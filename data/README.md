# ETF量化策略回测与交易归因分析系统

> 基于Python的量化交易策略研究框架，覆盖数据加载、策略回测、绩效评估、参数寻优、交易归因、可视化全流程。
> 项目源于ETF套利量化实习，将实习业务沉淀为可复现、可扩展的工程化代码。

## 项目背景

本项目诞生于**ETF一二级市场套利量化实习**。实习期间参与ETF折溢价套利业务，跟踪IOPV实时折溢价、完成竞价套利机会识别与交易日志记录，并对多份交易账表进行盈亏归因复盘。

为将实习业务经验沉淀为可复现的技术成果，独立开发了本套量化研究框架，实现：

- **策略回测**：将实习中观察到的交易逻辑（趋势跟踪、动量、均值回归）量化为可回测策略
- **绩效评估**：建立独立的量化指标体系，替代框架内置黑盒分析器
- **交易归因**：对实习交易日志进行多维度盈亏拆解，回答"钱怎么赚的、怎么亏的"
- **参数寻优**：用网格搜索替代人工调参，输出参数敏感性热力图

> 原始交易账表属于机构内部业务数据，出于保密仅本地留存，本仓库仅开源代码与分析输出结果。

## 核心功能

### 1. 多策略回测引擎

基于Backtrader封装统一回测引擎，支持三种经典策略横向对比：

| 策略 | 类型 | 逻辑 |
|------|------|------|
| 双均线（DualMA） | 趋势跟踪 | 短期均线上穿长期均线买入，下穿卖出 |
| MACD | 动量 | MACD线与信号线金叉/死叉判断动量方向 |
| 布林带（Bollinger） | 均值回归 | 价格触及下轨买入、上轨卖出 |

- 统一策略基类 `BaseStrategy`，自动记录每笔交易日志
- 新增策略只需继承基类并注册，无需修改回测引擎
- 支持单策略回测与多策略净值曲线横向对比

### 2. 独立绩效指标体系

不依赖Backtrader内置分析器，手动实现10余项量化指标，精确控制年化方式与参数：

| 类别 | 指标 |
|------|------|
| 收益 | 总收益率、年化收益率（复利） |
| 风险 | 最大回撤、年化波动率、下行波动率 |
| 风险调整收益 | 夏普比率、索提诺比率、卡玛比率 |
| 交易统计 | 胜率、盈亏比、平均持仓周期、最大连续亏损 |

- 编写14个单元测试验证指标计算正确性
- 所有指标基于日收益率序列计算，支持自定义无风险利率

### 3. 参数网格寻优

- 对双均线快慢线周期进行二维网格搜索
- 支持按夏普比率、年化收益率、卡玛比率多目标排序
- 输出Top10参数组合表 + 参数敏感性热力图
- 帮助识别参数稳定区间，避免单一最优值过拟合

### 4. 实习交易日志盈亏归因

`analysis_attribution.py` 读取实习交易账表Excel，输出多维度统计报表：

- **按标的统计**：各ETF代码的交易笔数、总盈亏、胜率、最大盈亏
- **按时段统计**：按交易小时聚合，识别高胜率交易时段
- **按日期统计**：每日盈亏汇总，盈利/亏损天数分布
- **套利标的统计**：8月折溢价套利标的、现差、套利类型分布
- **逐笔交易明细**：完整买卖时间、价格、盈亏导出

### 5. 可视化报告

使用Matplotlib生成：
- 多策略净值曲线对比图
- 净值与回撤联合分析图
- 参数寻优热力图
- 月度盈亏柱状图

## 项目架构

```
quant-strategy/
├── config/
│   ├── __init__.py
│   └── settings.py          # 全局配置（资金、手续费、滑点、策略参数）
├── src/
│   ├── __init__.py
│   ├── data_loader.py       # 数据加载（GBM模拟行情 / 真实数据可插拔）
│   ├── strategies.py        # 策略实现（双均线 / MACD / 布林带 + 统一基类）
│   ├── metrics.py           # 绩效指标计算（10+指标独立实现）
│   ├── backtest_engine.py   # 回测引擎封装（单策略 / 多策略对比）
│   ├── optimizer.py         # 参数网格寻优
│   ├── trade_analyzer.py    # 交易归因分析（5维度拆解）
│   └── visualizer.py        # 可视化图表生成
├── tests/
│   ├── test_metrics.py      # 绩效指标单元测试
│   └── test_data_loader.py  # 数据加载单元测试
├── data/                    # 原始交易账表（本地保密，不上传仓库）
│   └── README.md            # 数据目录说明
├── output/                  # 回测结果、归因报表、图表输出
│   ├── profit_by_code.csv   # 按标的盈亏统计
│   ├── profit_by_hour.csv   # 按时段盈亏统计
│   ├── profit_by_date.csv   # 按日期盈亏汇总
│   ├── arbitrage_targets.csv # 8月套利标的统计
│   ├── trade_details_all.csv # 逐笔交易明细
│   └── trade_logs_summary.csv # 交易日志文本汇总
├── main.py                  # 主入口：一键完整回测流程
├── run_optimization.py      # 参数寻优入口
├── analysis_attribution.py  # 实习交易日志盈亏归因分析
├── intern_report.md         # 实习复盘文档（ETF套利业务笔记）
├── requirements.txt         # 依赖清单
├── .gitignore               # 屏蔽data/原始Excel，防止数据泄露
└── README.md
```

### 设计原则

- **模块化**：各功能模块单一职责，独立可测试
- **可扩展**：策略基类统一接口，新增策略零侵入
- **可复现**：配置集中管理，模拟数据固定随机种子
- **工程化**：单元测试、配置分离、输出目录规范、数据保密隔离

## 快速开始

### 环境要求

- Python 3.9+
- 依赖库：backtrader, pandas, numpy, matplotlib, openpyxl

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行完整回测流程

```bash
python main.py
```

执行后依次完成：数据加载 → 双均线回测 → 交易归因 → 多策略对比 → 可视化生成，结果保存至 `output/`。

### 运行参数寻优

```bash
python run_optimization.py
```

对双均线快慢线参数网格搜索，输出Top10组合及参数热力图。

### 运行实习交易日志归因分析

```bash
python analysis_attribution.py
```

读取 `data/` 下交易账表Excel，输出6份多维度统计报表至 `output/`。

> 需将实习交易Excel放置于 `data/` 目录（原始数据不上传仓库）。

### 运行单元测试

```bash
pytest tests/ -v
```

## 回测配置说明

在 `config/settings.py` 中调整：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| initial_cash | 1,000,000 | 初始资金 |
| commission_rate | 0.0003 | 佣金费率（万三） |
| slippage | 0.001 | 滑点（千一） |
| risk_free_rate | 0.025 | 无风险利率（年化） |
| fast_period / slow_period | 5 / 20 | 双均线默认参数 |
| fast_range / slow_range | (3,20) / (20,60) | 参数寻优范围 |

## 数据源说明

项目默认使用**几何布朗运动（GBM）模拟行情数据**，无需网络即可运行，用于策略逻辑验证与框架测试：

- 跳过周末，生成真实交易日序列
- 价格路径符合GBM，带有趋势与波动
- OHLC价格关系合理（最高价≥收盘价≥最低价）
- 固定随机种子，结果可复现

如需接入真实行情，设置 `DataLoader.load(use_sim=False)`，底层通过yfinance获取真实ETF数据（需网络环境支持）。
